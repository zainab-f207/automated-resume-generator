**Automated Resume Generator**

A full-featured resume builder web application built with **ASP.NET Web Forms** and **SQL Server**, designed to help users create, edit, and export resumes in real-time. This platform includes support for multiple templates, user account roles (Admin & User), and export functionality in both PDF and HTML formats.
Built in **Visual Studio Community** using C#, ADO.NET, and JavaScript for seamless integration between backend logic and frontend interactivity.

**Features**

- **Professional Resume Templates**  
  Choose from multiple pre-built resume designs.

- **Live Resume Editing**  
  Dynamic input fields with real-time updates.

- **Save & Update Drafts**  
  Resumes are saved as HTML files and can be updated anytime.

- **Export as PDF or HTML**  
  Download resumes in clean formats with styling preserved.

- **User Roles**  
  - **Admin**: Manage users, templates, and resumes.  
  - **User**: Create, edit, and download their own resumes.

- **Database Integration**  
  All user and resume metadata is stored securely using SQL Server.

**Technologies Used**

| Stack | Tools |
|-------|-------|
| Frontend | HTML5, CSS3, JavaScript, Bootstrap |
| Backend | ASP.NET Web Forms, C#, ADO.NET |
| Database | SQL Server |
| PDF Generation | iTextSharp |

1. Open in Visual Studio
2. Set up SQL Server DB
3. Build and run the app
